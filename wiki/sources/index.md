# Sources Index

Entry point for the source-summary domain. Each page records one raw source — what it says, where, and which articles drew on it — so a claim in the vault can be traced back to the document it came from. A source summary is written in the vault's working language, English, regardless of the language the source itself is in; the traceability stays uniform, and a Persian source is still summarized in English. Summarized sources are listed as links; sources not yet summarized are listed as plain text.
