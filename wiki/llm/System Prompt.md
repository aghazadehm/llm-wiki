# System Prompt

**System Prompt** پیامی است که معمولاً اول کار (به عنوان پیام system) به مدل داده می‌شود تا چارچوب رفتاری و نوع پاسخ‌ها را مشخص کند. اثر این پیام معمولاً تا آخر همان مکالمه باقی می‌ماند.

## چرا مهم است

- **یک‌بار تنظیم می‌شود:** دیگر نیازی به تکرار مداوم دستورها نیست.
- **رفتار کلی مدل:** لحن، سبک و محدودیت‌ها را مشخص می‌کند.
- **یکپارچگی خروجی‌ها:** جواب‌ها همیشه منسجم و در یک سبک ثابت ارائه می‌شوند.

## قالب ساختاریافته

```
# هویت
تو یک [نقش] هستی که [توضیح کوتاه].

# قوانین
- همیشه [قانون ۱]
- هرگز [قانون ۲]
- اگر [شرط]، [عمل]

# محدودیت‌ها
- جواب‌ها حداکثر [تعداد] جمله باشند
- فقط به [زبان/موضوع] جواب بده

# فرمت خروجی
- جواب را به صورت [فرمت] بده
```

## نکات حرفه‌ای

1. **کوتاه و موثر بنویس:** سیستم پرامپت هم توکن مصرف می‌کند.
2. **رفتارهای «نباید» را هم بگو:** فقط نگو چه کار کند؛ بگو چه کار نکند.
3. **با ورودی‌های غیرمنتظره تستش کن.**
4. **از مثال استفاده کن:** می‌توان چند نمونه سوال و جواب ایده‌آل قرار داد.

## محدودیت امنیتی

سیستم پرامپت یک لایه از دفاع است، نه تمام آن: برای کارهای حساس باید کنترل بیرون از مدل هم وجود داشته باشد.

## My Understanding

System Prompt شخصیت مدل را تعریف می‌کند. یک سیستم پرامپت خوب باید کوتاه، واضح و ساختاریافته باشد. این تنها لایه امنیتی نیست و برای کارهای حساس باید با سایر لایه‌های دفاعی ترکیب شود.
