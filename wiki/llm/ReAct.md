# ReAct

**ReAct (Reasoning and Acting)** تکنیکی است که به مدل اجازه می‌دهد بین برنامه‌ریزی کوتاه و انجام عمل جابجا شود. مدل می‌تواند ابزارهای خارجی (مثل جستجوی وب، ماشین حساب، API) را صدا بزند، نتیجه را ببیند و بر اساس آن تصمیم بعدی را بگیرد.

## مثال

```
کاربر: قیمت لحظه‌ای بیت‌کوین چند است و با بودجه ۵۰۰ دلاری چقدر می‌توانم بخرم؟

پلن: ۱) قیمت لحظه‌ای را از ابزار می‌گیرم. ۲) با ماشین‌حساب ۵۰۰ را تقسیم بر قیمت می‌کنم.
عمل: فراخوانی ابزار get_price("BTC").
مشاهده: قیمت فعلی: [قیمت] دلار.
عمل: فراخوانی ابزار calculator("500 / [قیمت]").
مشاهده: نتیجه: [مقدار] بیت‌کوین.
جواب نهایی: قیمت فعلی بیت‌کوین حدود [قیمت] دلار است و با ۵۰۰ دلار تقریباً [مقدار] بیت‌کوین می‌توانی بخری.
```

## چرا مهم است

- مدل می‌تواند به اطلاعات به‌روز دسترسی پیدا کند.
- می‌تواند محاسبات پیچیده را به ابزار دیگری بسپارد.
- مدل می‌تواند از طریق ابزارها و APIها با دنیای بیرون تعامل کند.

## تفاوت با CoT

CoT فقط استدلال است؛ ReAct استدلال + عمل + مشاهده است. ReAct پایه بسیاری از سیستم‌های ایجنتی است.

## My Understanding

ReAct پلی است بین مدل زبانی و دنیای واقعی. مدل مانند یک مغز است که ابزارها را به عنوان دست‌ها و چشم‌ها استفاده می‌کند. بدون ابزار، مدل فقط می‌تواند متن تولید کند؛ با ابزار، می‌تواند کار واقعی انجام دهد.
